# Верхняя панель в стиле Cyberpunk 2077: спецификация

Дата: 2026-11-06. Модуль `night-city-ui` («Найт-Сити — общий интерфейс»), Foundry 12.331, cyberpunk-red-core v0.92.4. Основа — 0.3.5 (коммит c660907).

## 1. Цель и границы

Верхняя панель Night City UI сейчас выглядит как графитовая полоса со значками. Она должна стать шапкой в стиле меню Cyberpunk 2077, как в `night-city-menu`, и показывать пользователю больше, чем сейчас.

В работу входят пункты 7, 10–14 из каталога улучшений от 2026-11-06. Пункты 8 и 9 пользователь исключил: «Персонаж» продолжает открывать лист системы или карточку REDLINE, а ранг роли, репутация, IP и €$ в панели не показываются.

Остальной интерфейс модуля (окна, чат, сайдбар, левая панель) пока не меняется и остаётся в графитовой палитре 0.3.5. Новая панель — первый кусок будущего общего стиля.

## 2. Решения пользователя

| Вопрос | Решение |
|---|---|
| Вид панели | Вариант A: красные заглавные вкладки с подчёркиванием, активная бирюзовая со свечением, как шапка `night-city-menu`. Макет — `docs/design/topbar-mock-A.png` |
| Q/E | Работают только внутри окон разделов. Q открывает предыдущий доступный раздел, E — следующий, текущее окно закрывается. На краях листание останавливается |
| Статус | Раунд и чей ход, таймер DEADLINE. Кто в сети и пауза — не нужны |
| Кому статус | Всем. Таймер виден по собственной настройке видимости DEADLINE |
| Щелчок по сцене | Открывает сцену у себя. Отдельная кнопка «Сделать активной» у мастера переносит игроков сразу, без подтверждения |
| Список сцен у мастера | Карточки сцен навигации и ниже поиск по всем сценам мира с фильтром папки |
| Недоступные пункты | Модуль не установлен или выключен — пункта нет. Модуль есть, доступа нет — замок и причина в подсказке |
| Клавиши разделов | Новых не добавляем. Подписываются только существующие: Q/E, Alt+N, клавиша Quick Insert |
| Поиск | Через Quick Insert (`QuickInsert.open()`), без него кнопки нет |
| Выкладка | Каждая проверенная на стенде сборка ставится в рабочую Foundry пользователя для его теста (память `feedback_ncu_deploy_to_working_foundry`) |

## 3. Поведение

### 3.1. Вкладки

Порядок: ПЕРСОНАЖ · АГЕНТ · ТОРГОВЛЯ · СЕТЬ · ГОРОД · БОЙ. У мастера рядом с АГЕНТОМ остаётся стрелка пульта ведущего.

Состояние каждого раздела вычисляется из двух признаков:
- **installed** — нужный модуль включён в мире. Для «Персонажа» и «Боя» всегда да.
- **available** — у пользователя есть доступ сейчас. Это прежние условия 0.3.5 вместе с прежней причиной отказа.

Итог: `hidden` (не установлен), `locked` (установлен, но нет доступа) или `ready`. Пункт `locked` тусклый, с замком. Причина видна в подсказке при наведении и при фокусе с клавиатуры. Щелчок, как и раньше, показывает её уведомлением.

Активная вкладка — раздел, которому принадлежит `ui.activeWindow`, если это окно ещё открыто:

| Раздел | Чьё окно |
|---|---|
| Персонаж | лист актёра типа `character` или `mook` |
| Агент | элемент с классом `nca-app` или `nca-workspace` (night-city-agent 0.17.3) |
| Торговля | id `night-city-market-window` (night-city-market 0.3.2) |
| СЕТЬ | объект `globalThis.CRNS.ui` (cpr-netrunning 1.12.0) |
| Город | Атлас не установлен ни в одной доступной Foundry, признак окна проверить нельзя. Вкладка не подсвечивается, пока модуль не появится |
| Бой | отдельное окно трекера боя. Если активного окна раздела нет, а в сайдбаре открыта вкладка «Бой», подсвечивается «Бой» |

### 3.2. Q/E

**Отложено.** 2026-11-07 пользователь попросил сейчас не делать листание Q/E. Раздел сохранён как решение на будущее; без отдельной команды его не реализовывать.

Две клавиши регистрируются через `game.keybindings` (`prevSection` — Q, `nextSection` — E), пользователь может их переназначить. Обработчик срабатывает, только если активное окно принадлежит одному из разделов, иначе возвращает `false`, и клавишу получают другие. Поля ввода ядро Foundry само не передаёт в обработчики. Окно `night-city-menu` к разделам не относится, его собственные Q/E не затрагиваются.

Следующий раздел — ближайший `ready` в нужную сторону. На краю ничего не происходит, и подсказка этой клавиши тусклая. Переход закрывает текущее окно и выполняет действие раздела, как щелчок по вкладке.

### 3.3. Статус

- В бою текущей сцены (правило 0.3.5): `РАУНД 3 · ХОДИТ ВЕСПЕР`. До первого раунда — `ПОДГОТОВКА К БОЮ`, вне боя ничего.
- Скрытый участник: игрок видит `ХОД СКРЫТ`, мастер — имя.
- Длинное имя обрезается многоточием, полное — в подсказке. Щелчок открывает вкладку «Бой».
- Таймер — `cpr-deadline` `api.getState()`: подпись и `мм:сс`, раз в секунду, только пока таймер идёт. На паузе таймер тусклый со значком паузы. Последние 60 секунд он красный и пульсирует, без пульсации при `prefers-reduced-motion`. По окончании — `ВРЕМЯ ВЫШЛО`.
- Таймер показывается, только если DEADLINE включён и таймер видим этому пользователю. Собственный блок `#cpr-deadline-hud` при этом скрыт и возвращается при выключении темы. Щелчок мастера вызывает `api.open()`.

### 3.4. Сцены

- В панели — название просматриваемой сцены. Щелчок раскрывает панель карточек. Состав карточек — как у штатной навигации: `navigation && visible`, плюс активная и просматриваемая сцена.
- На карточке превью (`scene.thumb`, без него — заглушка с названием), метки `АКТИВНА · ИГРОКИ ЗДЕСЬ` и `ВЫ ЗДЕСЬ`.
- Щелчок по карточке — `scene.view()`. У мастера кнопка «Сделать активной» — `scene.activate()`.
- У мастера ниже поиск по всем сценам по названию и фильтр папки, до 20 результатов, щелчок — `view()`.
- В шапке панели ссылка «Штатная навигация» показывает прежнее меню сцен ядра с контекстными командами.
- Escape и щелчок мимо закрывают панель.

### 3.5. Подсказки клавиш и поиск

- Подписи клавиш строятся из текущих привязок `game.keybindings.get(...)`. Переназначенная клавиша меняет подпись, снятая убирает её.
- Кнопка поиска видна, только если Quick Insert включён и `globalThis.QuickInsert?.open` — функция. Подпись — его текущая клавиша. Окно Quick Insert получает палитру панели.

### 3.6. Размеры

- Высота панели в просторном режиме — 58 px (была 48). Все зависимые отступы считаются от одной переменной `--ncu-bar-height`.
- От 1600 px — полный вид. От 1280 до 1599 — поиск значком, статус короче (`Р3 · ВЕСПЕР`, `04:32`). Меньше 1280 — вкладки значками с подписью в подсказке.
- Непросторный режим 0.3.5 (плавающая полоса) получает тот же вид, но сохраняет свою геометрию.

## 5. Ошибки

- Действие раздела бросило исключение — уведомление «Не удалось открыть инструмент», ошибка в консоль с префиксом `night-city-ui |`, панель работает (как в 0.3.5).
- API DEADLINE или Quick Insert отсутствует или изменился — элемент скрыт, одно предупреждение в консоль за сессию.
- Исключение при отрисовке панели — Foundry не ломается: тема снимается до перезагрузки, возвращается штатная навигация, выводится уведомление.
- Удалённые бой или сцена убирают статус, сцена без превью получает заглушку.

## 6. Проверка

- `node --test`: состояния разделов, выбор активного, шаги Q/E с краями, подписи клавиш, текст статуса и таймера, фильтр и поиск сцен. Прежние 85 тестов проходят.
- Стенд `D:\FoundryDev\bench` с копиями night-city-agent, night-city-market, cpr-netrunning, quick-insert, cpr-deadline. Мастер и игрок, 1920/1440/1280:
  - вкладки и замки;
  - активация сцены переносит игрока;
  - бой со скрытым участником;
  - таймер: идёт, на паузе, последняя минута, конец, скрыт от игроков;
  - Q/E;
  - выключение темы возвращает исходный вид;
  - в консоли нет ошибок `night-city-ui`.
